# Ecommerce-Data-Analysis-Project

# E-Commerce Sales, Customer & Product Analytics

## Project Overview

This project focuses on analysing e-commerce business performance using SQL, Microsoft Excel and Power BI.

The analysis covers sales performance, customer distribution, product performance, regional sales, order delivery and product returns.

The objective is to transform raw business data into meaningful insights that can support data-driven business decisions.

## Tools & Technologies

- PostgreSQL / SQL
- Valentina Studio
- Microsoft Excel
- Power BI
- DAX
- Power Query

## Dataset Description

The project uses five datasets:

| Dataset | Description |
|---|---|
| Customers | Customer information |
| Products | Product and category details |
| Orders | Order and shipping information |
| Order Items | Sales, quantity, revenue, cost and profit |
| Returns | Return details and refund amounts |

## Project Workflow

### 1. SQL Analysis
- Database and table creation
- Data quality checks
- Duplicate and missing value checks
- Referential integrity validation
- Primary and foreign key creation
- Business KPI calculations
- SQL views for reporting

### 2. Excel Analysis
- Overall KPI analysis
- Monthly sales analysis
- Category performance
- Product performance
- Regional sales analysis
- Order delivery analysis
- Return and refund analysis

### 3. Power BI Dashboard
- Business performance overview
- Product performance analysis
- Returns and delivery analysis
- Project explanation
